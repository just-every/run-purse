# Procurement verification

Run `node src/base/contract-docs.mjs write`, then `node src/base/contract-docs.mjs check`, before the edition source lock. `rer check` validates the contract and source; Verify runs the native purchasing and browser journeys.

The public target and current status live only in CONTRACT.md and its generated ACCEPTANCE.md and docs/CLAIMS.md projections. Earlier hand-written journeys are preserved in CHANGELOG.md. Local fixtures and transport-edge fakes do not establish a real mailbox receipt or vendor-tenant qualification.
